Memories live in this directory, committed, with an entry in `MEMORY.md`.

**Why:** the FerroHEALTH owner's standing rule across every repository: a
per-user note is invisible to the next session on another machine.

**How to apply:** write the file here, add its index line, and commit it with
the change that taught it.
